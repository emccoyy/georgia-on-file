# Georgia on Film

An interactive 3D map of real, **public** filming locations across Georgia, showing what was shot where.

> Unofficial fan project. Not affiliated with any studio, network, or the Georgia Film Office.

Built with Next.js (App Router), TypeScript, Tailwind CSS, MapLibre GL JS and Framer Motion. Map data © OpenStreetMap contributors via [OpenFreeMap](https://openfreemap.org); terrain from [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/). No API keys required.

## Run it

```bash
npm install        # also copies the MapLibre worker into public/vendor
npm run dev        # http://localhost:3000
```

Useful URL flags: `?quality=low` / `?quality=high` to force a performance tier, `?debug` to expose the map as `window.__map` in devtools.

## Data

Everything lives in `src/data/`:

| File | What |
|---|---|
| `locations.json` | Filming locations (must be public places) |
| `productions.json` | Films and shows; `locationIds` must mirror each location's `productionIds` |
| `schema.ts` | Zod schema: the source of truth for fields and allowed types |
| `geo/` | Georgia outline + mask (generated by `npm run build:geo` from US Census data via `us-atlas`) |

Validate after any edit:

```bash
npm run validate:data
```

It checks required fields, `public: true`, at least one https source per entry, coordinates inside Georgia (with a small tolerance for piers and beaches), unique ids, and two-way links between locations and productions.

Every seeded entry is `verified: false`. Flip it to `true` only after you've checked the claim against its sources. `approximateCoords: true` means the pin is a landmark or town-center approximation. `note` is an internal fact-check note and is never shown on the site.

## Content rules

- **Public places only.** Parks, landmarks, businesses open to the public, streets, campuses. Never private residences, even if fans have identified them.
- **Hand-curated with sources.** No scraping IMDb or any site whose terms forbid it. Every entry needs a source URL.
- **No copyrighted images.** No film stills, posters, or logos. Images must be Wikimedia Commons with license and attribution shown, or the built-in placeholder.
- **Original writing.** Descriptions and loglines are written in our own words, not copied from sources.
